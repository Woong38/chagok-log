3
양쪽에 모두 있는 과제는 우측에만 (계속)이 자동으로 붙는다.
4
확인 요청은 보고문에 포함되지 않는다 — 빠진 것을 알려주는 용도다.

Notes

예시 데이터 — 본 화면의 과제·담당자·수치는 전부 가상으로 구성했다. 실제 업무 내용과 무관하다.

저장 — 기록은 브라우저 저장소에 보관된다. 저장소를 쓸 수 없는 환경에서는 「데이터」 탭의 JSON 내보내기·가져오기로 이어서 사용한다.

연계 — 같은 기능을 대화형으로도 쓸 수 있다. 문장 다듬기·판단이 필요할 때는 스킬 방식이 유리하다.
