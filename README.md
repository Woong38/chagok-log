# 차곡Log

**일별 업무기록 기반 주간보고 자동조립 Tool** — 차곡차곡 쌓아, 마감날 한 번에

하루 30초 기록을 쌓아 격주 주간보고(「주요 추진 실적 및 계획」)를 좌·우 2단 양식으로 자동 조립한다.
설치·서버·계정이 필요 없는 단일 HTML 파일이며, 기록은 사용하는 브라우저에만 저장된다.

## 쓰는 법

1. **일별 기록** — 과제명과 한 일만 적는다 (매일 30초)
2. **과제 관리** — 배경·담당자·완료예정일 등록 (과제당 최초 1회)
3. **보고서 생성** — 기간 지정 → 2단 보고서 + 시스템 입력용 텍스트

입력 문법: 줄바꿈으로 항목 구분, 맨 앞 `-` 는 부연(`·`), `>` 는 화살표(`→`)

## 자동으로 처리되는 것

- **같은 과제 병합** — 여러 날 기록이 보고서에서 한 블록으로 합쳐진다
- **좌·우 자동 배분** — 실적기간 기록은 좌측, 계획 등록분은 우측. 양쪽에 있으면 `(계속)` 자동 표기
- **배경 재사용** — 과제당 1회 등록 후 모든 회차에 자동 반영
- **날짜 변환** — `2026-09-18` → `9.18(금)`, 상태에 따라 완료일 / 완료(예정)일 구분
- **누락 점검** — 미기재 항목·예정일 경과·누락 후보를 별도 제시 (보고문 미포함)

## 데이터

- 기록은 브라우저 저장소에만 보관되며 외부로 전송되지 않는다
- 저장소를 쓸 수 없는 환경에서는 「데이터」 탭의 JSON 내보내기·가져오기로 이어서 사용한다
- 본 저장소의 모든 예시 데이터는 가상 업무·가상 인명으로 구성했다
